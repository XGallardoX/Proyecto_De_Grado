# Fuentes

Subconjunto latino (incluye tildes y ñ) de dos fuentes con licencia SIL
Open Font License 1.1, tal como las sirve Google Fonts:

- `inter.woff2`: Inter (variable, pesos 400 a 700), de Rasmus Andersson.
- `jetbrains-mono.woff2`: JetBrains Mono (variable, pesos 400 a 600), de JetBrains.

Van dentro del repo para que la interfaz se vea igual sin conexión
(`--ventana`). Si faltan, `app.css` cae a las fuentes del sistema.
